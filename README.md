# Polymarket Bot

Bot Telegram qui surveille les marchés Polymarket et envoie des alertes automatiques.

## Variables d'environnement

- `TELEGRAM_TOKEN` : Token de votre bot Telegram
- `CHAT_ID` : Votre Chat ID Telegram
- `THRESHOLD` : Seuil de variation en points (défaut: 10)
- `INTERVAL_MINUTES` : Intervalle entre les scans en minutes (défaut: 5)
